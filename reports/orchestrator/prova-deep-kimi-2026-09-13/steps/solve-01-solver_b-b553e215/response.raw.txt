Ragionamento sintetico ma completo.
Errore di implementazione principale: summarize() filtra a e b separatamente con np.isfinite, quindi perde l’allineamento per-caso. Nei dati forniti: dopo il filtro separato, A ha validi c1,c3,c4 con media (0.2+0.6+0.4)/3 = 1.2/3 = 0.4; B ha validi c2,c4 con media (0.1+0.5)/2 = 0.6/2 = 0.3; delta = 0.4-0.3 = +0.1 e il codice dichiara vincitore B. Ma i casi validi per entrambi sono solo c1 e c4: media A (0.2+0.4)/2 = 0.3, media B (0.3+0.5)/2 = 0.4, differenza A−B = −0.1; quindi, “loss inferiore è migliore”, A è migliore sui casi effettivamente confrontabili. Il controesempio è nel dataset stesso: filtrare separatamente ribalta il segno rispetto al confronto appaiato.
Secondo errore di implementazione: la regola del vincitore è fragile/invertita se si passa al confronto appaiato. Con delta = a.mean()-b.mean() e loss più bassa migliore, A vince quando delta < 0, non quando delta > 0. Esempio minimale: a=[0.1], b=[0.2] dà delta=-0.1, ma il codice restituisce winner="B", sbagliato. Anche delta == 0 viene trattato come vittoria di B per default.
Problema metodologico principale: lo split casuale per record/cell_id non garantisce “linee cellulari mai viste”. Se cell_id ha più record o se cell_line compare in più record, record della stessa linea possono finire sia in train sia in test; allora il test non è su linee mai viste. Controesempio: due record r1,r2 con la stessa cell_line=L; la permutazione può mettere r1 in train e r2 in test, violando l’obiettivo dichiarato. Correzione minima: split per gruppo cell_line, non per record, con seed fisso e controllo di disgiunzione.
Altro problema metodologico: la media globale su pochissimi casi e con missingness parziale non misura generalizzazione. Qui i casi validi per entrambi sono n=2; c2 ha solo B, c3 ha solo A, quindi non sono confrontabili. Anche con la maschera corretta non si ottiene un intervallo di confidenza, un test, una varianza, né si dimostra che i missing siano missing-completely-at-random. Se i missing dipendono dal modello o dalla linea cellulare, escludere le coppie può introdurre bias.

import numpy as np

def summarize_paired(loss_a, loss_b):
    a = np.asarray(loss_a, dtype=float)
    b = np.asarray(loss_b, dtype=float)
    if a.shape != b.shape:
        raise ValueError("loss_a e loss_b devono avere la stessa forma e lo stesso ordinamento dei case_id")
    mask = np.isfinite(a) & np.isfinite(b)
    av, bv = a[mask], b[mask]
    d = av - bv  # <0 significa A migliore, dato che loss più bassa è migliore
    return {
        "n_used": int(mask.sum()),
        "n_dropped": int((~mask).sum()),
        "mean_a": float(av.mean()) if mask.any() else float("nan"),
        "mean_b": float(bv.mean()) if mask.any() else float("nan"),
        "delta_a_minus_b": float(d.mean()) if mask.any() else float("nan"),
        "winner": ("A" if d.mean() < 0 else "B" if d.mean() > 0 else "tie") if mask.any() else "undefined",
        "paired_deltas": d.tolist(),
    }
